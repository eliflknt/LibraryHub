\# LibraryHub



\## Proje Amacı

LibraryHub, ASP.NET Core Web API kullanılarak geliştirilen bir kütüphane yönetim sistemi projesidir.



\## Kullanılan Teknolojiler

\- .NET 8

\- ASP.NET Core Web API

\- Swagger

\- Git \& GitHub



\## Kurulum



1\. Repoyu klonlayın.

2\. Projeyi Visual Studio ile açın.

3\. Projeyi çalıştırın.

4\. Swagger arayüzüne tarayıcı üzerinden erişin.
